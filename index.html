AI Medical Chatbot

Retrieval-Augmented Generation medical Q&A system

  • Runs locally and answers from verified medical literature instead of general LLM knowledge, which lowers hallucination risk.
  • LangChain orchestrates Llama 2 (7B-Chat) with a FAISS vector store; chunks overlap by 50 characters and use all-MiniLM-L6-v2 embeddings.
  • CTransformers lets it run fully offline on standard CPUs. I built the Flask front end.

Blood Donation System

Web platform connecting donors, hospitals and patients

  • Real-time blood stock across hospitals, replacing the phone-based coordination of similar Bangladeshi platforms.
  • Blood compatibility matching and a donor eligibility tracker built on the 56-day donation cycle.
  • JWT auth with four roles (Admin, Hospital, Donor, User), BCrypt hashing and prepared statements against SQL injection.
  • Shortage alerts and an analytics dashboard for donation trends, fulfillment rates and stock versus demand.
  • React.js

  • PHP REST API

Smart Parking Management System
